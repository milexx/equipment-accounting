# Текстовый Макет Схемы

```text
┌─────────────────────────────┐
│ Гибридная разработка        │
│ - человек ставит задачу     │
│ - LLM пишет код и документы │
│ - контроль качества         │
│ - git commit                │
└──────────────┬──────────────┘
               │ push
               v
┌─────────────────────────────┐          ┌───────────────────────────────┐
│ GitHub origin/dev           │          │ Корпоративный GitLab          │
│ текущий внешний репозиторий │ зеркало  │ целевая точка управления      │
└──────────────┬──────────────┘ ───────> └──────────────┬────────────────┘
               │ ручное развертывание                    │ пайплайн
               v                                         v
┌─────────────────────────────┐          ┌───────────────────────────────┐
│ Демо VPS                    │          │ GitLab CI/CD                  │
│ - systemd/uvicorn           │          │ - тесты                       │
│ - PostgreSQL                │          │ - сборка артефакта            │
│ - локальные фото            │          │ - миграции                    │
│ - demo/database вход        │          │ - развертывание               │
└─────────────────────────────┘          └──────────────┬────────────────┘
                                                        │
                                                        v
                                      ┌──────────────────────────────────┐
                                      │ Корпоративная среда              │
                                      │ - веб-приложение                 │
                                      │ - PostgreSQL                     │
                                      │ - S3-совместимое хранилище фото  │
                                      │ - Keycloak / корпоративный вход  │
                                      │ - резервные копии / мониторинг   │
                                      └──────────────────────────────────┘
```

Основная мысль: разработка сейчас гибридная - человек управляет задачей и проверкой, LLM пишет код и документы; демо живет на VPS и обновляется вручную; целевой вариант - зеркало или перенос в корпоративный GitLab, затем управляемый пайплайн в корпоративный контур.

# Спецификация Диаграммы

## Цель

Показать путь решения от разработки до демо VPS и целевой корпоративной среды.

## Ключевые Зоны

1. Разработка сейчас:
   - рабочая папка проекта;
   - локальные проверки;
   - Git commit.

2. Текущий внешний контур:
   - GitHub `origin/dev`;
   - демо VPS;
   - веб-приложение;
   - PostgreSQL;
   - файловое хранилище фото;
   - ручной deploy.

3. Целевой корпоративный контур:
   - корпоративный GitLab;
   - GitLab CI/CD;
   - тесты;
   - сборка артефакта или контейнера;
   - миграции БД;
   - deploy веб-приложения;
   - корпоративный PostgreSQL;
   - S3-совместимое хранилище фото;
   - Keycloak или другой провайдер входа;
   - резервное копирование и мониторинг.

## Логика Потока

Сейчас:

```text
Разработка -> GitHub -> ручное развертывание -> демо VPS
```

Целевой вариант:

```text
Разработка -> корпоративный GitLab -> пайплайн -> корпоративная среда
```

## Акценты

- Демо VPS - временный стенд, не промышленный контур.
- Корпоративный GitLab - будущая точка управления кодом и пайплайном.
- PostgreSQL уже используется как основная БД.
- S3 и Keycloak предусмотрены архитектурно как будущие подключения.
- Перенос - это задача развертывания и настройки окружения, а не переписывания приложения.

## Не Включать В V1

- подробную схему таблиц;
- сетевые ACL;
- подробную модель ролей Keycloak;
- внутренние компоненты оценщика.

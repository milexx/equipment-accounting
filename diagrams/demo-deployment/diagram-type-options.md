# Варианты Типа Диаграммы

## 1. Архитектурная Схема

Показывает компоненты и связи: разработка, Git, демо VPS, GitLab, пайплайн, корпоративный сервер, PostgreSQL, S3, Keycloak.

Плюсы:

- лучше всего отвечает на вопрос "что где живет";
- удобно для руководства и технических участников;
- сразу видны текущий и целевой контуры.

Минусы:

- меньше показывает пользовательский бизнес-процесс.

Рекомендация: выбрать этот вариант.

## 2. Карта Процесса Развертывания

Показывает шаги: разработка -> commit -> push -> pipeline -> миграции -> deploy -> проверка.

Плюсы:

- хорошо объясняет будущий CI/CD.

Минусы:

- хуже показывает инфраструктурные блоки и заглушки S3/Keycloak.

## 3. Сравнение "Сейчас / Целевой Контур"

Показывает две колонки: демо VPS сейчас и корпоративная среда потом.

Плюсы:

- хорошо подходит для управленческого решения о переносе.

Минусы:

- слабее показывает движение кода и пайплайн.

## Выбор Для Текущей Задачи

Выбран гибрид: архитектурная схема с явным разделением "сейчас" и "целевой корпоративный контур".

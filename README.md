# Equipment Accounting

Проект: веб-приложение для централизованного учёта оборудования головным подразделением и регионами.

## Цель

Заменить ручной Excel-процесс системой, где регионы сами вносят данные по своему оборудованию, а центр видит общую картину, управляет типами оборудования, полями, фильтрами и выгрузками.

## Текущий Статус

Инициализирован проект, сохранена исходная постановка задачи, зафиксированы рабочие решения и финализированы требования, архитектура и модель БД для MVP.

Ключевой архитектурный акцент:

- FastAPI + PostgreSQL + SQLAlchemy + Alembic.
- Jinja2 + HTMX вместо сложного SPA.
- Гибкие поля оборудования через модель типов и `JSONB`.
- Фото в файловой системе, не в БД.
- Задел под Keycloak и S3 через абстракции.

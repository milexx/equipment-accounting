# Постановка Задачи

## Бизнес-Контекст

Есть головное подразделение, отвечающее за централизованный учёт оборудования, и много удалённых точек/регионов, где оборудование фактически находится.

Сейчас процесс ведётся через Excel:

- много версий файлов;
- ошибки при ручном заполнении;
- потеря данных;
- долгий сбор и сверка в центре;
- при недостатке данных процесс часто начинается заново.

## Цель

Создать веб-приложение для централизованного учёта оборудования, в котором:

- регионы сами ведут свои записи;
- центр видит все регионы;
- типы оборудования и наборы полей настраиваются без изменения кода;
- каждая единица оборудования подтверждается фотографиями;
- данные можно фильтровать, просматривать и выгружать.

## Границы MVP

Входит в MVP:

- учёт регионов;
- добавление, редактирование и просмотр оборудования;
- разные типы оборудования с разными динамическими полями;
- обязательная загрузка 1-5 фото;
- фильтрация и пагинация;
- экспорт ограниченного набора записей;
- простая аутентификация по таблице/токену;
- файловое хранение фото.

Не входит в MVP, но должно быть архитектурно предусмотрено:

- Keycloak;
- S3;
- сложная ролевая модель;
- массовый импорт Excel;
- аналитические отчёты;
- мобильное приложение;
- полнотекстовый поиск.

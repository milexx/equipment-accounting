# Открытые Вопросы

Эти вопросы нужно закрыть до финального ТЗ.

## Роли И Доступ

1. В MVP один пользователь/токен на регион или несколько пользователей внутри региона?
2. Нужна ли отдельная роль администратора центра?
3. Может ли регион удалять свои записи или только архивировать?
4. Может ли центр видеть историю изменений по каждой записи?

## Процесс Учёта

1. Нужна ли модерация центра после добавления записи регионом?
2. Какие статусы оборудования нужны?
3. Есть ли жизненный цикл: черновик, на проверке, принято, требует уточнения, архив?
4. Нужно ли возвращать запись региону на доработку?

## Данные

1. Какие базовые поля обязательны для всех типов оборудования?
2. Нужен ли уникальный инвентарный номер?
3. Нужен ли серийный номер как обязательное или условно обязательное поле?
4. Какие справочники нужны кроме регионов и типов?

## Динамические Поля

1. Какие типы полей точно нужны в MVP?
2. Нужны ли справочники внутри динамических полей?
3. Нужны ли маски ввода?
4. Нужны ли поля, обязательные только при определённых условиях?
5. Кто может менять набор полей после того, как по типу уже внесены записи?

## Фото

1. Какие форматы фото разрешены: JPEG, PNG, HEIC, WebP?
2. Нужно ли выбирать главное фото?
3. Можно ли заменить фото после создания записи?
4. Нужно ли хранить EXIF?
5. Нужно ли сжимать оригиналы или хранить как загружено?

## Экспорт И Импорт

1. Экспорт нужен в CSV, XLSX или оба формата?
2. Нужен ли импорт из текущих Excel-файлов?
3. Должен ли экспорт включать ссылки на фото?
4. Нужны ли шаблоны выгрузок для разных типов оборудования?

## Эксплуатация

1. Где будет храниться файловое хранилище фото?
2. Как будет делаться backup БД и фото вместе?
3. Есть ли требования к журналам безопасности?
4. Где будет развёрнута система: один сервер, VM, Docker, Kubernetes?
5. Кто администрирует PostgreSQL?

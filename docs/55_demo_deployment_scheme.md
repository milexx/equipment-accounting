# Схема разработки и развертывания

![Схема разработки, демо-развертывания и переноса в корпоративную среду](/static/docs/development_deployment_scheme.svg)

## Что показывает схема

- Разработка ведется гибридно: человек задает требования, проверяет результат и принимает решения, LLM помогает писать и менять код.
- Репозиторий Git остается центральной точкой фиксации изменений.
- Демо VPS используется как стенд для показа и проверки текущего состояния решения.
- Корпоративный контур требует отдельных решений по инфраструктуре и безопасности.
- В целевом варианте перенос в корпоративную среду может идти через зеркало репозитория в корпоративный GitLab и согласованный процесс поставки.

## Важные ограничения

- Демо VPS не является промышленной средой.
- Заглушки под S3 и Keycloak показывают направления интеграции, но не заменяют корпоративные решения.
- Перенос базы, веб-приложения, хранения файлов и авторизации нужно проектировать с учетом правил корпоративного контура.

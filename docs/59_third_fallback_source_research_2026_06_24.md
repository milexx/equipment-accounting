# Исследование Третьего Резервного Источника После `avito` И `youla`

Дата: 2026-06-24

## Вопрос

Что может быть третьим источником в цепочке после `avito` и `youla`, если `youla` тоже начнет возвращать блокировку?

Требования к кандидату:

- публичные объявления с ценой, URL и названием;
- достаточно широкое покрытие для IT/office оборудования;
- возможность регулярного ручного или полуавтоматического fallback;
- без платного внешнего сервиса;
- пригодность к нашему полю данных: `title`, `price`, `url`, `location`, `date`.

## Короткий Вывод

Лучший кандидат на третий fallback: `gde.ru`.

Почему:

- дает обычные товарные карточки с ценой, адресом, датой и описанием;
- показывает живую выдачу по нашим типовым категориям: ноутбуки, МФУ, серверы;
- в выдаче есть как отдельные объявления, так и категорийные страницы с несколькими позициями;
- на примерах из поиска были найдены текущие страницы с `Lenovo ThinkPad T14`, `Kyocera M2040dn` и серверными позициями Dell/HPE/IBM;
- по функциональной форме он ближе к нашему текущему `Avito/Youla` workflow, чем магазинные каталоги.

## Кандидаты

### 1. `gde.ru`

Плюсы:

- широкая classifieds-структура;
- по поиску видны `title`, `price`, `address`, `date`, `description`;
- есть категории и города, что позволяет формировать воспроизводимый запрос;
- по ноутбукам и оргтехнике были найдены свежие страницы в 2026 году;
- по серверной тематике есть отдельные позиции и категории с текущими публикациями.

Примеры:

- [Lenovo ThinkPad T480 на Gde.ru](https://moskva.gde.ru/c/lenovo_thinkpad_t480_14_quot_core_88342693.html)
- [Kyocera M2040dn на Gde.ru](https://himki.gde.ru/c/kuosera_m2040dn_86850992.html)
- [раздел ноутбуков Lenovo в Москве](https://moskva.gde.ru/yelektronnaya_tehnika/kompyutery/noutbuki/lenovo)
- [раздел серверов Gde.ru](https://moskva.gde.ru/c/ibm_system_x3650_m4_hd_84182498.html)

Минусы:

- exact-match по `Dell PowerEdge R740` нашелся хуже, чем по ноутбукам и МФУ;
- часть выдачи состоит из магазинных/профессиональных продавцов, а не только частных объявлений;
- региональное покрытие не гарантированно равномерное по всей стране.

Оценка:

- `best_third_source_candidate`

### 2. `kupiprodai.ru`

Плюсы:

- тоже дает живые карточки с ценой, адресом, датой и описанием;
- есть совпадения по `Kyocera M2040dn` и `Lenovo ThinkPad T14`;
- в выдаче встречаются ноутбуки, оргтехника, серверы и комплектующие;
- структура страницы достаточно читаемая для парсинга.

Примеры:

- [Kyocera M2040dn в Химках](https://mo.kupiprodai.ru/office/himki_comp_Kyocera_M2040dn_10085008)
- [Lenovo ThinkPad T570 в Санкт-Петербурге](https://spb.kupiprodai.ru/office/sanktpeterburg_comp_noutbuk_Lenovo_ThinkPad_T570_7417645)
- [сервер на kupiprodai.ru](https://msk.kupiprodai.ru/office/moscow_comp_server_lntel_2hXeon_E5645_24_9208076)

Минусы:

- exact-match по серверу Dell R740 в поиске показан слабее;
- часть выдачи выглядит как магазинный/профессиональный ассортимент;
- в некоторых карточках акцент на актуальности объявления слабее, чем хотелось бы для daily fallback.

Оценка:

- `backup_of_backup`

### 3. `farpost.ru`

Плюсы:

- сильная и структурированная выдача по технике;
- хорошо показывает цены, регионы, сортировку и много позиций на одной категории;
- по ноутбукам Lenovo и части серверной тематики есть богатая выдача;
- на страницах видно много полей, пригодных для парсинга.

Примеры:

- [Lenovo ThinkPad категория на Farpost](https://www.farpost.ru/vladivostok/tech/computers/notebooks/+/Lenovo+ThinkPad/)
- [пример Kyocera на Farpost](https://www.farpost.ru/vladivostok/tech/computers/printers/mfu-lazernoe-kyocera-ecosys-m2040dn-82277353.html)
- [пример Dell R740-related server page](https://www.farpost.ru/vladivostok/tech/computers/network/server-1u-dell-r640-xeon-4215r-256gb-ram-8x480ssd-vo-vladivostoke-109477910.html)

Минусы:

- сильный региональный уклон в сторону Дальнего Востока;
- exact-match по нашим московским/общероссийским запросам хуже, чем у `gde.ru`;
- для текущей цепочки это скорее specialist fallback, чем универсальный третий источник.

Оценка:

- `regional_specialist`

## Что Отсекаем

Не беру в третий fallback:

- retail/магазинные каталоги без вторичного рынка;
- общие search APIs типа Exa или SERP API;
- vendor-scraping сервисы, если они требуют отдельного платного контракта;
- площадки с очень узкой географией или слабым покрытием наших трех опорных категорий.

## Почему Не `youla`-Аналог В Поисковой Форме

Нужен не просто еще один search API, а источник, который:

- сам является площадкой объявлений;
- дает видимую цену и ссылку;
- может быть разобран в тот же доменный контракт, что и `avito`/`youla`;
- пригоден как логичный третий fallback без отдельного vendor-слоя.

`gde.ru` этому соответствует лучше остальных найденных вариантов.

## Рекомендация По Цепочке

Предлагаемая последовательность:

```text
avito -> avito_duff89 -> youla -> gde.ru
```

Если нужен более осторожный вариант:

```text
avito -> avito_duff89 -> youla -> gde.ru -> kupiprodai.ru
```

Для дальневосточных категорий можно держать `farpost.ru` как региональный дополнительный источник, но не как основной universal third fallback.

## Что Нужно Проверить Перед Интеграцией

1. Один живой HTTP-probe по `gde.ru` без рандомизации.
2. Проверка, что можно стабильно извлечь:
   - `title`;
   - `price`;
   - `url`;
   - `location`;
   - `date` или признак свежести.
3. Проверка по нашим трем ключевым позициям:
   - `Lenovo ThinkPad T14`;
   - `Kyocera M2040dn`;
   - `Dell PowerEdge R740`.
4. Если exact-match по Dell слабый, определить допустим ли broad-server fallback для этой категории или нужен отдельный vendor path.

## Итог

На текущем этапе `gde.ru` выглядит лучшим третьим источником после `avito` и `youla`.

`kupiprodai.ru` и `farpost.ru` полезны как резервные кандидаты, но `gde.ru` дает лучший баланс:

- ширина каталога;
- читаемость карточек;
- совпадения по нашим типовым IT-позициям;
- пригодность к ручному/полуавтоматическому fallback.

## Зафиксированное Решение

Дата фиксации: 2026-06-24.

Текущая рабочая цепочка для оценщика:

```text
avito -> avito_duff89 -> youla -> gde.ru
```

Если `gde.ru` окажется нестабильным или даст блокировку, следующий резервный шаг:

```text
kupiprodai.ru
```

`farpost.ru` остается региональным дополнительным кандидатом, но не базовым третьим источником в основной цепочке.
